# ZKsnark-notebook
This Jupyter Notebook implements the steps described in https://arxiv.org/pdf/1906.07221.pdf
The goal is explore the concepts described in the article and implement them to provide working examples of Zero Knowledge proofs protocols.

Such concepts as polynomials and modulo arithmetic are explored via examples to start on us on a good footing so that we are ready to tackle the more complicated concepts such as homomorphic encryption.

In the end, we will have a working implementation of a Zero Knowledge proof protocol that uses polynomials for proving knowledge of generic type. But to get there, we need to overcome many obstacles.
